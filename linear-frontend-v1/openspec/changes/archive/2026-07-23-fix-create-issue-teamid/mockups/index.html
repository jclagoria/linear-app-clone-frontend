Issue Creation — teamId Data Flow

No visual layout changes. This mockup demonstrates the data flow for the teamId fix.

1
Team Selection
User selects a team in the sidebar TeamSelector. The selected teamId is written to a shared TeamStore.
2
Open Create Issue Modal
User clicks "New Issue" button on IssuesPage. Modal opens with the create-issue form.
3
Submit Form
User fills form fields and clicks Submit. handleCreateIssue reads currentTeamId from TeamStore.
4
API Call
createIssue({ title, description, status, priority, teamId }) sends POST to /api/v1/issues with teamId in body.
5
Success / Error
On 201: issue added to store, modal closes, success toast. On error: error toast, modal stays open.
